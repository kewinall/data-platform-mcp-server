# v0.5.0 — ETL Metadata / Lineage Integration

## 繁體中文

v0.5 將 Data Platform MCP Server 與 enterprise-etl-platform 的 normalized ETL metadata contract 整合，同時維持清楚的 Repository responsibility boundary。

### Added

- read-only ETL metadata contract adapter
- filesystem JSON contract adapter
- synthetic demo adapter
- list_etl_pipelines
- get_etl_pipeline
- get_etl_pipeline_steps
- get_etl_pipeline_dependencies
- get_etl_table_lineage
- search_etl_metadata
- etl://pipeline/{pipeline_id} resource
- classification / search / lineage / file contract regression tests
- ETL metadata integration documentation

### Engineering boundary

enterprise-etl-platform 仍是 metadata producer、migration truth 與 lineage truth。

data-platform-mcp-server 仍是 standardized governed access layer，不實作 Pentaho/Hop parser、migration converter、RAG、Incident RCA 或 model routing。

### Security / failure behavior

所有 ETL metadata tools 都是 read-only，且通過既有 scope、audit、identity、telemetry boundary。Invalid / unsupported metadata fail closed；MCP 不會發明缺少的 lineage。

## English

v0.5 adds a governed read-only access contract for normalized ETL metadata produced by enterprise-etl-platform.

It adds filesystem and synthetic adapters, six MCP tools, an ETL pipeline resource, regression tests, and explicit lineage/capability-boundary handling while keeping ETL parsing and truth production outside this repository.

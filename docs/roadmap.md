- stdio / Streamable HTTP

- API token/RBAC policy
- Audit log

## v0.4 — Production Delivery
- Kubernetes + Helm
- OIDC and multi-tenancy
- OpenTelemetry metrics/traces
- External Secrets examples
- Offline / air-gapped bundle

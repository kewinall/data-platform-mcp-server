# v0.4 — Production Delivery

## 繁體中文

v0.4 將前幾版的 MCP/Data Platform 功能推進到可展示企業落地方式的版本。

### Identity
- MCP SDK bearer gate
- static token reference mode
- OIDC/JWT + JWKS
- Keycloak / Entra examples
- role mapping
- tenant claim mapping

### Authorization
- reader / analyst / operator / admin
- per-tool scopes
- tenant-aware source isolation
- cross-tenant source denial

### Observability
- OTLP/HTTP traces
- invocation counter
- latency histogram
- audit ↔ trace ID correlation

### Kubernetes
- Helm v3 chart
- non-root
- read-only root filesystem
- seccomp RuntimeDefault
- capabilities drop ALL
- ServiceAccount token disabled
- resource limits
- probes
- PDB
- optional HPA
- NetworkPolicy

### Secrets
- existing Kubernetes Secret
- External Secrets Operator v1
- Azure Key Vault Workload Identity example

### Air-gap
- Python wheelhouse
- OCI image tar
- Helm package
- SHA256 manifest
- verification script

### CI/CD
- Python 3.11/3.12
- Ruff / pytest / compile
- Docker build
- Helm lint/render
- pip-audit
- Trivy filesystem
- Trivy rendered Kubernetes configuration
- CI/Security gated Release
- Helm chart Release asset

## English

v0.4 is the production-delivery milestone. It does not claim that one reference chart replaces an organization's platform standards; instead, it demonstrates the identity, authorization, observability, secrets, Kubernetes hardening, and offline-delivery controls expected when turning an MCP server into an enterprise service.

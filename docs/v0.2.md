# v0.2 — DataOps Integration

## 繁體中文

v0.2 將 v0.1 的 MCP 基礎骨架提升成可實際串接 DataOps 平台的版本：

- 啟用 Airflow 3 `/api/v2` read-only adapter。
- OpenSearch ETL Log search。
- Grafana Loki `query_range` search。
- Catalog / Operations / Logs 三類 adapter 可獨立切換。
- 新增 MCP Resources：
  - `platform://capabilities`
  - `catalog://{source}/{schema}/{table}`
- 新增 MCP Prompts：
  - `incident_triage`
  - `data_discovery`
- 使用官方 `Client(mcp)` 進行 protocol-level integration tests。

## English

v0.2 turns the v0.1 protocol foundation into an integration-ready DataOps MCP server. Airflow 3, OpenSearch, and Loki adapters are read-only and independently configurable. MCP resources and prompts add application-controlled context and user-controlled workflows alongside model-controlled tools.

## Safety boundary

v0.2 still contains no mutation tool. It does not trigger DAGs, clear tasks, update databases, delete indexes, or write log data.
